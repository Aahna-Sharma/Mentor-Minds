Mentor Minds is an educational platform designed to help students, teachers, and administrators access and manage academic resources like notes, tutorials, previous year question papers, practical work, and syllabi for B.Tech CSE, BCA, MCA, and IT courses.

🚀 Features

Role-based Access

Students: View and download content
Teachers: Upload content (edit only with admin permission, cannot delete)
Admins: Add, edit, and delete content
Authentication

Login via Google, Facebook, or Email (method to be finalized)
Content Organization

Category-based navigation (e.g., CSE → Semester → Subject → Module)
Easy access to syllabus and learning materials stored on Google Drive
Google Drive Integration

Publicly available syllabus and study resources
Direct view/download options
🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
